# 阶段② 三维建模（二维图 → 参数化模型）

## 从二维图读出三维结构

1. **先认视图**：平面图给半径/环向分布，立面图给高度与竖向关系，剖面给内部构造，工况图给运动状态。
2. **逐条对齐构件名**：图上的文字标注（如"撑杆/套环/铰节点"）就是模型里的 `module` 名，
   名称一致能避免后续沟通成本。
3. **用几何量而非目测**：同名字符串的坐标差就是真实尺寸（如"立柱"两条竖线相距 800 → 直径 0.8 m）；
   把每个参数的来源写进注释（图纸图元 / 交底书文字 / 假设）。
4. **对称性优先**：环向均布（8 个模块）用 `for (k = [0:n-1]) rotate([0,0,k*360/n])`，
   不要逐个手写。
5. **机构要解算，不要摆样子**：有铰接+滑动副的结构（撑杆+套环）应按约束求解
   （见下），否则动画会"看着像但物理不对"。

## 必须实现的接口

模型文件（`model/device.scad`）对外只暴露一个入口，段落模板据此驱动：

```openscad
module device(theta = 0, pull = 0, water_z = 0, step = N_PARTS,
              explode = 0, section = false, show_skin = true) { ... }
```

- `theta/pull` 工况变形；`water_z` 调节/环境量；`step` 装配步序；`explode` 爆炸分离；`section` 半剖。
- 参数覆盖约定：需要被 `param_sweep` 扫描的参数写成
  `P_x = is_undef(SET_P_X) ? 默认 : SET_P_X;`
- 精度覆盖：`$fn = is_undef(SET_FN) ? 64 : SET_FN;`、`coil_seg = is_undef(SET_COIL_SEG) ? 8 : ...`。
- 单色：`colorize = is_undef(SET_MONO) ? true : !SET_MONO;`，统一用 `tint(C_xxx)` 上色。

## 机构运动学（滑环类结构）

给定刚体杆的位姿（中心 `C`、方向 `u`）与固定铰点 `H`，套环位置由 `|C + t·u − H| = L`
解出（取靠近初值的根）；弹簧/阻尼的长度因此**由几何导出**，拉压方向自然正确。
用 `check_kinematics.py` 扫描参数，选出与图纸受力标注一致的那组
（例：−12°、内移 900 mm 时"弹簧1 压、弹簧2/3 拉、阻尼压"全部吻合）。

## 建模质量检查

- `openscad_run.py --build-stl` 会返回面片数、包围盒与**流形**判定；非流形要查自交/重复面。
- 逐段渲染前先跑一次整机静帧（`figures/`），确认构件齐全、比例合理。
- 尺寸来源存疑的参数，写进交付说明的"假设清单"，并在图上用不同颜色/图例区分。
