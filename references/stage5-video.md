# 阶段⑤ 视频（时间轴、字幕、配乐、成片）

## 顺序不能颠倒

1. `narration.py tts`：先逐句合成旁白 → 得到**真实时长** → 生成时间轴与帧数；
2. `storyboard.py render`：按帧数渲染（`$t` 驱动，关键节点由旁白时间轴换算）；
3. `narration.py compose`：烧字幕 + 编码分段 MP4/GIF；
4. `final_film.py`：片头片尾 + 配乐 + ducking 混音 + 响度归一 + 合成完整版。

因为时间轴来自旁白本身，**叠音问题在结构上被排除**；只有"换声线"时才需要
`voice_fit.py` 把新声线用 atempo 对齐到既有时间轴（比例 = 自然时长 ÷ 目标时长）。

## 字幕与画面

- 字幕条固定在底部（默认 150 px 高、白色不透明 92%），逐句切换；
- 左上角常驻段落标题（`用途｜标题`）；
- 断行优先在标点处，避免行首出现「、」「，」；
- 中文用系统字体（微软雅黑 / 苹方 / Noto CJK），缺失字体时自动回退。

## 配乐与混音

- 优先使用用户提供的曲子（`音乐/` 目录或 `--music`）：曲子比成片长就截取，
  短就循环并在接缝处 1.5 s 交叉淡化；
- 任何曲子都**统一归一化到 `music_bed_rms_db`（默认 −33 dBFS RMS）**，换曲子不用重调平衡；
- ducking：旁白出现时用 `sidechaincompress` 自动压低配乐（旁白必须 `asplit`，见 troubleshooting）；
- 最终 `loudnorm` 到 −16 LUFS / −1.5 dBTP。

## 验收（脚本已自动断言）

| 项 | 判据 |
|---|---|
| 人声清晰度 | 人声段电平 − 纯配乐段电平 ≥ 8 dB |
| 整片响度 | −16 LUFS ±1 LU |
| 时长一致 | 各段时长与 `timeline.json` 一致（帧数/帧率换算） |
| 字幕同步 | 每句字幕窗口 = 该句旁白时间槽 |

人工复核：完整播放一遍，确认语音不被音乐盖住、片头片尾信息正确、术语与交底书一致。

## 编码参数

渲染 1920×1440 / 20 fps → 成片 1920×1590（含字幕条），H.264 CRF 19–20、AAC 192 kb/s、
`+faststart`（便于 PPT 插入与网页播放）。GIF 供 Word/微信使用（960 宽、12 fps）。
