# 阶段④ 附图（彩色渲染 + 黑白线稿）

## 视图选择

| 用途 | 视角 | 说明 |
|---|---|---|
| 立体图（交底书/申请文件常用） | `front-right-top-iso` | 等距视角信息量最大 |
| 主视/侧视/俯视 | `front`/`right`/`top` | 与图纸三视图对应，便于比对 |
| 内部构造 | 去掉外罩（`show_skin=false`）或 `section=true` | 剖切面统一浅灰 |
| 黑白专利附图 | `SET_MONO=true` 单色立体图 | 白底灰阶，打印友好 |
| 尺寸/装配关系 | `lineart.py` 正投影线稿（SVG/DXF/PNG） | DXF 可直接进 AutoCAD 加标号与尺寸 |

## 出图规范

- 背景纯白、无坐标轴、无网格；构件按图例配色（同一构件在视频与附图中颜色一致）。
- 装配关系复杂时出**爆炸图**；运动关系复杂时出**初始位 + 极限位**对照图。
- 每张图配一句图题，参数表另附（参数名 / 取值 / 来源），把"假设值"标出来。
- 分辨率：静帧 1920×1440 起；线稿按矢量交付（SVG/DXF），PNG 仅作预览。

## 与 CAD 协作

`lineart.py --formats dxf` 产出的 DXF 使用 AC1006 ASCII 格式，AutoCAD 可直接打开：
建议在此图层上补尺寸标注与零件序号，再导出 PDF 作为正式附图。
比对原图时，把 DXF 叠到原 DWG 上检查比例（两边都按 mm 建模，比例应为 1:1）。

## 校验

- 渲染图非空且尺寸正确（`openscad_run.py` 返回包围盒，可与图纸尺寸对账）；
- 线稿 PNG 由 SVG 折线重绘，若为空白说明 `projection()` 没有产生轮廓（模型不闭合或视角转错）；
- 附图与视频使用同一模型文件，避免"图文不一致"。
